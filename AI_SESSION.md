# Работа с ИИ-агентом

Сокращённая подборка ключевых пользовательских запросов из рабочей сессии, не полный экспорт чата.
Разработка велась по шагам с обсуждением SQL, валидации параметров и округления денежных сумм.

1. Создать новую функцию расчёта по объёму по аналогии с существующей функцией расчёта по весу.
2. Объяснить `COALESCE`, назначение его второго параметра и проверку отрицательных объёмов.
3. Создать API долей рейса по объёму.
4. Объяснить `FILTER_VALIDATE_INT`, ограничение `min_range` и отличие от приведения `(int)`.
5. Добавить в карточку рейса таблицу распределения стоимости с загрузкой данных из API.
6. Временно сохранить старую таблицу по весу и показать новую ниже, чтобы сравнить результаты.
7. Добавить API предпросмотра и применения счетов за месяц. Предпросмотр не должен менять БД,
   повторное применение не должно менять данные и создавать дубли.
8. Добавить в интерфейс кнопку предпросмотра и форму редактирования незаполненных объёмов грузов.
9. Проверить проект по заданию: https://jobassist.ru/aktech/phpvac-online/test-task.html.
10. Удалить вес из нового API и таблицы по объёму, чтобы итоговый код соответствовал решению,
    которое было показано в записи экрана.

Результат: отдельная функция расчёта по объёму, API рейса и счетов, экран предпросмотра и применения,
форма объёмов, проверки на изолированных базах. Старый расчёт по весу оставлен для сравнения.
Ограничения и оставшиеся шаги явно указаны в README.
